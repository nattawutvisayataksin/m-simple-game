## 2. แนวคิดหลัก

ปราสาท KUB ถูกมอนสเตอร์จาก "ดินแดน glitch" ยกเวียนตี ผู้เล่นเป็นแม่ทัพวางหอคอยบนลานจุดที่ออกแบบไว้ของแผนที่
เพื่อหยุดคลื่นศัตรูก่อนถึงปราสาท ใช้เงินทองจากการล่ามอนสเตอร์
ก่อสร้าง/อัปเกรดสู้ไปทีละคลื่นจนรอดคลื่นสุดท้าย

## 3. ระบบหลัก 7 ชิ้น (ตาม playbook tower-defense)

1. **ทางเดินมอนสเตอร์** — waypoint lane 1 เส้นหลัก + แยก 1 จุด (Kingdom Rush มี fork) · ขนาด map 1152×648 ไม่มีกล้องเลื่อน (เพิ่มตอน map ใหญ่)
2. **เจนคลื่น** — ข้อมูลคลื่นต่อรอบ: `(ชนิด, จำนวน, ช่วงห่าง)` + HP โต ~1.15× ต่อคลื่น + ปุ่ม "เรียกคลื่นถัดไป" ที่ได้โบนัสถ้าเรียกเร็ว (ให้ตัดสินใจเสี่ยง)
3. **หอคอย 4 สาย (ชุด Kingdom Rush)** — แดง = นักธนู (ยิงเร็วรายเดี่ยว), เขียว = จอมเวท (เจิดช้า ทะลุเกราะ), ส้ม = ปืนใหญ่ (AoE ช้า), ฟ้า = ค่ายทหาร (ส่ง soldier บล็อกเดินชนกัน) — อัปเกรด 1→2 ได้, ขายคืน 60%
4. **จุดวางแบบ fix (Kingdom Rush style)** — ลานจุด 5 จุดบนแผนที่ กดเพื่อเปิดเมนูสร้าง
5. **เศรษฐกิจ** — ฆ่ามอนสเตอร์ได้ทอง, คลื่นจบโบนัส, มอนสเตอร์หลุดผ่านปราสาท = เสียชีวิตทีละ 1 + ทองนั้นหายด้วย (นอกจาก HP)
6. **มอนสเตอร์** — 4 ชนิดขั้นต้น: กบยักษ์เขียว (แกนหลัก), น้ำเงินวิ่งเร็ว, หมัดหินสีเทา (เกราะหนา ต้านนักธนู), ม่วงยักษ์ (บอสคลื่นสุดท้าย)
7. **UI พรีวิวคลื่น** — ไอคอนศัตรูในคลื่นถัดไป + จำนวนเงิน/ชีวิต/HUD ตามเกม 1

**ฮีโร่ Kubi** — หน่วยเดินได้ 1 ตัวที่ผู้เล่นสั่งย้ายจุดยืน ร่วมบล็อกซึ่งหน้า + ทักษะพิเศษใช้เวลาคูลดาวน์ (แผนขยายหลังมีตัวบล็อกกลุ่มแล้ว)

## 4. ผังสนามแนวคิด (สนาม 1152×648)

ประตูศัตรู (ซ้ายบน) → ถนนคดเคี้ยวผ่านป่าเมือง → แยก 2 ทางกลับมาบรรจบกัน → ปราสาท KUB (ขวาบน)
ลานหอคอย 5 จุด กระจายครอบคลุมเส้นทาง · หลังบ้านฝั่งล่างเติมด้วยน้ำหนูเมือง/ฟาร์ม/ประดับสวย

## 5. ระยะพัฒนา (prototype-fast เหมือนเกม 1)

- **T1 กองพลศิลป์ ก้าวกระโดด** (ทำก่อน — แก้จุด "ฉากแย่/เล็กจนมองไม่เห็น"): ภาพพื้นหลังเขียนเดียวทั้งสนาม + มอนสเตอร์ 3 ตัว + ฮีโร่ 64px + ป้อม 4 สาย — ต้องอนุมัติภาพ concept ทุกตัว- **T2 โครงเกม**: แผนที่ + ทาง waypoint + จุดกำเนิด/ปราสาท + มอนสเตอร์เดินตามทาง (ครบจนเห็น "มอนเดินมาปะทะปราสาท")
- **T3 หอคอยที่ยิงได้**: ลานจุด + เมนูสร้าง + การเล็ง + ปืนถึงขอบเขต (เริ่ม 1 สาย = นักธนู แล้วขยายอีก 3)
- **T4 คลื่น + economy + lives**: เจนคลื่นตามข้อมูล + ทองต่อฆ่า + ขอบ/ชนะ 8–10 คลื่น
- **T5 ฮีโร่ + อัปเกรด/ขาย**: Kubi สั่งย้าย + ป้อม 1→2, หัวเมนูเปลี่ยน
- **T6 โปรกรมเสียง**: เพลง chiptune ต่อยอดจาก generate_music.ps1 + SFX ยิง/ฆ่า/หลุด/เมนู (ฟรีทั้งหมด)
- **D2 บันทึกสถิติ**: reuse ระบบ save ของเกม 1 โดยตรง (นับคลื่นสูงสุดที่รอด / ด่านผ่า)

### เกณฑ์ตัดสิน (เหมือนเกม 1)
- ผู้เล่นต้องรู้สึก "มีทางเลือกทุกครึ่งนาที" ถ้าไม่มี = กลไกมีปัญหา แก้ก่อนแต่งภาพ
- ต้องมองเห็นตัวละครชัด ใหญ่ ฉากสวยกว่าเกม 1 จากภาพเดียวดูไม่ต้องถาม "ความรู้สึกตอบแทนที่" ไม่ตอบ = ระยะ T1 ทำซ้ำ
