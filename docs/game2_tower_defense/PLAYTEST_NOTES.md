## 3. Hero — เปลี่ยนเป็นนักดาบฟันระยะใกล้ ต้องสวย

- คำสั่ง: เปลี่ยนฮีโร่เป็นดาบฟัน (melee) ระยะใกล้

- ทิศทางแก้:

  - Key PixelLab C เหลือ 31/40 — เผื่อไว้ gen ตัวละครหลัก
  - อนิเมต 3 จังหวะ: idle / เดิน / ฟัน ให้ดูเป็นตัวเดียวกันจริง
- ต้องไม่ทำเทสเดิมพัง: test_t5 (ฮีโร่ฟาด/โดนรุม/เกิดใหม่), test_t9, test_t10
