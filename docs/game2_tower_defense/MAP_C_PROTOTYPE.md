# Map C prototype — ที่ราบรอยแยก

แผนที่ทดลองสำหรับเปรียบเทียบ layout/การอ่านถนนกับแผนที่เดิม โดยต่อกับเกมจริงและไม่แก้ค่าของ Map A/B

## เปิดดู

รัน `games/game2_tower_defense` ตามปกติ แล้วเลือก **ที่ราบรอยแยก · ทดลอง** จากหน้าเลือกแผนที่ ภาพจับ gameplay อยู่ที่ [`map_c_prototype.png`](../../games/game2_tower_defense/screenshots/map_c_prototype.png)

## สิ่งที่ทดลอง

- พื้นที่เล่นเต็มจอ 1152×648; ถนนหนึ่งเส้นจากซ้ายบนไปป้อมปลายทางขวา ผ่านช่วงตรงยาวและโค้งหักศอกที่เห็นจังหวะชัด
- วาดถนนเป็นริบบอนต่อเนื่องจากขอบไหล่ทาง → ขอบดิน → ผิวดิน → ผิวกลาง พร้อมรอยหินตามแนวถนน ไม่วาดวงกลมทับทุก waypoint
- แยกสนามหญ้าออกจากถนน และใช้ลานหญ้าสามโซนเป็นจุดอ่านพื้นที่ ไม่ได้จำกัดตำแหน่งสร้าง
- ไม่มีฐานตายตัว; กด `B` แล้วคลิกพื้นเพื่อเลือกจุดวางได้ทั่วสนาม โดยกันถนนและเว้นระยะระหว่างป้อม
- ใช้คลื่น มอน ป้อม ฮีโร่ และ HUD ระบบเดิม เพื่อเทียบความครอบคลุมป้อมและการอ่านตำแหน่งระหว่างเล่นได้

## ขอบเขตต้นแบบ

พื้นสนามและพร็อพเป็นรูปทรง procedural ใน `main.gd` เพื่อทดลองสเกลและการแบ่งพื้นที่ก่อนทำชุดภาพ production; ยังไม่ได้เพิ่มชุดแอนิเมชันหรือเปลี่ยนดีไซน์ตัวละคร/ป้อมจากเกมหลัก
