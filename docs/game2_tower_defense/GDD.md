## 2. แนวคิดหลัก

ปราสาท KUB ถูกมอนสเตอร์จาก "ดินแดน glitch" ยกเวียนตี ผู้เล่นเป็นแม่ทัพเลือกตำแหน่งตั้งป้อมได้ทั่วสนาม
เพื่อหยุดคลื่นศัตรูก่อนถึงปราสาท ผู้เล่นเริ่มเกมด้วยทอง 0 และต้องพา Kubi ล่ามอนสเตอร์หาเงินก่อนสร้างป้อม
ก่อสร้าง/อัปเกรดสู้ไปทีละคลื่นจนรอดคลื่นสุดท้าย

## 3. ระบบหลัก 7 ชิ้น (ตาม playbook tower-defense)

1. **ทางเดินมอนสเตอร์** — waypoint lane 1 เส้นหลัก + แยก 1 จุด (Kingdom Rush มี fork) · ขนาด map 1152×648 ไม่มีกล้องเลื่อน (เพิ่มตอน map ใหญ่)
2. **เจนคลื่น** — ข้อมูลคลื่นต่อรอบ: `(ชนิด, จำนวน, ช่วงห่าง)` + HP โต ~1.15× ต่อคลื่น + ปุ่ม "เรียกคลื่นถัดไป" ที่ได้โบนัสถ้าเรียกเร็ว (ให้ตัดสินใจเสี่ยง)
3. **หอคอย (เป้าหมายระยะยาว 4 สาย)** — แดง = นักธนู (ยิงเร็วรายเดี่ยว), เขียว = จอมเวท (ยิงช้า ทะลุเกราะ), ส้ม = ปืนใหญ่ (AoE ช้า), ฟ้า = ค่ายทหาร (ส่ง soldier บล็อกเดินชนกัน) — อัปเกรด 1→2 ได้, ขายคืน 60%; *ต้นแบบที่เล่นได้มีนักธนู ปืนใหญ่ และป้อมเวท*
4. **ตำแหน่งวางป้อม** — กด B + คลิกเพื่อเลือกตำแหน่งได้ทั่วสนาม ไม่มีฐานตายตัว; ห้ามทับถนน ประตู หรือป้อมอื่น
5. **เศรษฐกิจ** — เริ่มทอง 0; ฮีโร่หรือป้อมฆ่ามอนสเตอร์ได้ bounty, คลื่นจบโบนัส, มอนสเตอร์หลุดผ่านปราสาท = เสียชีวิตทีละ 1
6. **มอนสเตอร์** — เป้าหมายระยะยาว 4 ชนิด; *ต้นแบบปัจจุบันมี 3 ชนิด: กบ, กิ้งก่า และโกเลมหิน (ช้า, HP 95, ลดดาเมจกายภาพ 65%; ป้อมเวทแก้ทาง)*
7. **UI พรีวิวคลื่น** — ไอคอนศัตรูในคลื่นถัดไป + จำนวนเงิน/ชีวิต/HUD ตามเกม 1

**ฮีโร่ Kubi** — หน่วยเดินได้ 1 ตัวที่ผู้เล่นสั่งย้ายจุดยืนและโจมตีศัตรูใกล้ตัวอัตโนมัติ; ทักษะพิเศษ/การบล็อกศัตรูยังเป็นแผนขยาย ไม่ได้อยู่ในต้นแบบปัจจุบัน

## 4. ผังสนามแนวคิด (สนาม 1152×648)

ประตูศัตรูซ้ายบน `(258,190)` → ถนนวกลง/กลับขึ้นหลายช่วงราว 1,272 px → ประตูปราสาทขวาบน `(810,450)`
ตำแหน่งวางป้อมเป็นอิสระทั่วพื้นที่สนาม โดยเว้นถนน/ประตู/ป้อมอื่น

## 5. ระยะพัฒนา (prototype-fast เหมือนเกม 1)

- **T1 กองพลศิลป์ ก้าวกระโดด** (ทำก่อน — แก้จุด "ฉากแย่/เล็กจนมองไม่เห็น"): ภาพพื้นหลังเขียนเดียวทั้งสนาม + มอนสเตอร์ 3 ตัว + ฮีโร่ 64px + ป้อม 4 สาย — ต้องอนุมัติภาพ concept ทุกตัว- **T2 โครงเกม**: แผนที่ + ทาง waypoint + จุดกำเนิด/ปราสาท + มอนสเตอร์เดินตามทาง (ครบจนเห็น "มอนเดินมาปะทะปราสาท")
- **T3 หอคอยที่ยิงได้**: ลานจุด + เมนูสร้าง + การเล็ง + ปืนถึงขอบเขต (เริ่ม 1 สาย = นักธนู แล้วขยายอีก 3)
- **T4 คลื่น + economy + lives**: เจนคลื่นตามข้อมูล + ทองต่อฆ่า + ขอบ/ชนะ 8–10 คลื่น
- **T5 ฮีโร่ + อัปเกรด/ขาย**: Kubi สั่งย้าย + ป้อม 1→2, หัวเมนูเปลี่ยน
- **T6 โปรกรมเสียง**: เพลง chiptune ต่อยอดจาก generate_music.ps1 + SFX ยิง/ฆ่า/หลุด/เมนู (ฟรีทั้งหมด)
- **D2 บันทึกสถิติ**: reuse ระบบ save ของเกม 1 โดยตรง (นับคลื่นสูงสุดที่รอด / ด่านผ่า)

### เกณฑ์ตัดสิน (เหมือนเกม 1)
- ผู้เล่นต้องรู้สึก "มีทางเลือกทุกครึ่งนาที" ถ้าไม่มี = กลไกมีปัญหา แก้ก่อนแต่งภาพ
- ต้องมองเห็นตัวละครชัด ใหญ่ ฉากสวยกว่าเกม 1 จากภาพเดียวดูไม่ต้องถาม "ความรู้สึกตอบแทนที่" ไม่ตอบ = ระยะ T1 ทำซ้ำ

| D. เล็งเป็นระบบ + juice | พรีวิวคลื่นไอคอน (×จำนวน + จุดอ่อนชนิด) + โหมดเล็งต่อป้อม 4 แบบ | ปุ่ม/คีย์ 4: **ใกล้ปราสาท / นำหน้า (เพิ่งเข้าวง) / ชี้เป้าหนัก (โกเลม-บอส) / เก็บเศษ (ฟินิชเลือดน้อย)**; ปืนใหญ่ = จอสั่น + อนุภาคระเบิด, มอนรั่ว = จอสั่น + ขอบจอแดงกะพริบ |

**เวลาเล่นเดี๋ยวนี้:** เลือกแผนที่ → ลากฮีโร่ไปฟาดมอนหาเงินทุนแรก → กด B + คลิกพื้นเพื่อสร้างป้อม 4 สาย ณ จุดที่เลือก → เลือกโหมดเล็งต่อป้อมตามพรีวิวคลื่นถัดไป → กรอดกองรัว 100 ตัว (คลื่น 1) → กด N เรียกคลื่นก่อนเก็บโบนัสต่อวิ → จัดการทุกชนิด + บอส 3 ตัว (คลื่น 2) ด้วย 20 ชีวิต → สถิติปั๊มค้างในหน้าเลือกแผนที่

**อัปเดตการเล่น:** ยกเลิกฐานตายตัวทั้งสี่จุดแล้ว ใช้ B + คลิกพื้นเพื่อเลือกจุดวางป้อมอย่างเดียวบนทุกแผนที่ โดยยังกันถนน ประตู และป้อมซ้อน
