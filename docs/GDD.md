# Game Design Document (GDD)

## 1. ข้อมูลทั่วไป

- **ชื่อเกม:** m-sample-game
- **ประเภทเกม:** ยังไม่กำหนด
- **แพลตฟอร์มเป้าหมาย:** ยังไม่กำหนด
- **เอนจิน:** Godot Engine
- **สถานะ:** อยู่ในขั้นตอนเริ่มต้น

## 2. แนวคิดหลักของเกม

พื้นที่สำหรับอธิบายแนวคิด เรื่องราว และประสบการณ์หลักที่ต้องการให้ผู้เล่นได้รับจากเกม

## 3. รูปแบบการเล่น

- การควบคุมตัวละคร: ยังไม่กำหนด
- เป้าหมายของผู้เล่น: ยังไม่กำหนด
- ระบบการเล่นหลัก: ยังไม่กำหนด
- เงื่อนไขชนะและแพ้: ยังไม่กำหนด

## 4. ตัวละคร

### Player

- ประเภท Node: `CharacterBody2D`
- ฉาก: `scenes/player.tscn`
- Node ภายใน:
  - `Sprite2D` สำหรับแสดงภาพตัวละคร
  - `CollisionShape2D` สำหรับตรวจสอบการชน

## 5. โลกและฉาก

รายละเอียดแผนที่ สภาพแวดล้อม ด่าน และองค์ประกอบต่าง ๆ ของโลกในเกม

## 6. ระบบเกม

รายการระบบที่วางแผนจะพัฒนา:

- [ ] ระบบควบคุมตัวละคร
- [ ] ระบบการชน
- [ ] ระบบกล้อง
- [ ] ระบบศัตรู
- [ ] ระบบไอเทม
- [ ] ระบบคะแนนหรือความคืบหน้า
- [ ] ระบบ UI
- [ ] ระบบเสียง

## 7. งานศิลป์และเสียง

- รูปแบบภาพ: ยังไม่กำหนด
- เพลงประกอบ: ยังไม่กำหนด
- เสียงเอฟเฟกต์: ยังไม่กำหนด

## 9. แผนการพัฒนา

1. กำหนดแนวคิดและรูปแบบการเล่น
2. สร้างระบบควบคุม Player
3. สร้างฉากทดสอบและระบบการชน
4. เพิ่มระบบเกมหลัก
5. เพิ่ม UI เสียง และงานศิลป์
6. ทดสอบและปรับปรุงเกม
