# คู่มือการเล่น — Kubi Coin Dash

## เนื้อเรื่อง (Goal)
ฝูงไวรัส "Glitch Bugs" บุกขโมย **เหรียญกองทุนเมือง KUB** ไปกองไว้จนเมืองสั่นคลอน
**Kubi** โรบอตหัวใจอบอุ่นตัวเล็ก ได้รับภารกิจเดียว: **ตามเก็บเหรียญคืนให้ครบทุกด่าน แล้วไต่ขึ้นยอดเขาเพื่อส่งเหรียญกลับสู่โรงหล่อเหรียญ**

- เก็บเหรียญให้มากที่สุด ห้ามโดนไวรัส/หนาม/หมดเวลา/ตกหุบเหว
- ชนะ = ผ่านด่าน 5 ครบ แตะธงบนยอดเขาด่านสุดท้าย

## ปุ่มควบคุม
| ปุ่ม | ทำอะไร |
|---|---|
| A / D หรือ ← / → | เดินซ้าย-ขวา |
| Space / W / ↑ | กระโดด (กดค้าง = สูง, ปล่อยกลางคัน = ขี่สั้น) |
| Shift | วิ่งเร็ว (จำเป็นกับช่องกว้างในด่าน 4-5) |
| R | เริ่มใหม่ทันที |
| Esc | กลับหน้าเมนู |

Controller ตั้งใจให้องใจ: Coyote time 0.12 วิ + Jump buffer 0.15 วิ — กระโดดไม่หลุดง่าย

## เหรียญ & คะแนน
- เหรียญเงิน = คะแนน 1 · **เหรียญทอง (เรืองแสง) = คะแนน 3** ต่อเหรียญ
- สถิติคะแนนสูงสุด + เวลาเร็วสุด เซฟอัตโนมัติ (พร้อม backup)

## ศัตรู
| ศัตรู | พฤติกรรม | จัดการ |
|---|---|---|
| **Glitch Walker** (แดง) | เดินสลับทางที่ขอบพื้น | **เหยียบหัว** เพื่อจัดการ + เด้งขึ้นได้ |
| **Glitch Hopper** (ฟ้า) | กระโดดเข้าหาผู้เล่นเป็นระยะ | เหยียบหัวได้เหมือนกัน — แต่ลมกระโดดของมันบาจ่ะ |
| หนามแดง | ขูดพื้นตายบนทางเดิน | กระโดดข้าม / ใช้แพลตฟอร์มข้างบน |

## ด่านทั้ง 5
1. **ถนนสายเอิ้น** (120 วิ) — ด่านไอลีน: พื้นต่อเนื่อง เรียนการเดิน/กระโดด/เหยียบศัตรู
2. **ทุ่งเหรียญเขียว** (120 วิ) — แพลตฟอร์มเลื่อนนอน + Hopper ตัวแรก
3. **ป่าไวรัสหนา** (150 วิ) — ศัตรู 6-8 ตัว หนามหนาแน่น
4. **หุบเหวแตกร้าว** (140 วิ) — **พื้นแตก 3 ท่อน ตกเหว = แพ้!** กู้ภาพด้วยแพลตฟอร์มเลื่อนขึ้น-ลงและ Shift วิ่งกระโดด
5. **ยอดเขาโรงหล่อเหรียญ** (160 วิ) — บทสุดท้าย: ไต่บันไดเขาใหญ่ ธงอยู่บนยอด

ทุกด่านเริ่มด้วย **แบนเนอร์ชื่อด่าน + คำใบ้** เด้งขึ้นกลางจอ เคลียร์ให้เข้าใจเป้าหมายทันที

## เสียวิไฟวิธีแพ้
โดนศัตรูด้านข้าง · โดนหนาม · หมดเวลา · **ตกหุบเหว (ด่าน 4-5)** → จอแสดงเหตุ + กด R เริ่มใหม่

## เทคขึ้นยอด (Tips)
- เหยียบหัวศัตรูจะได้ **เด้งสูงพิเศษ** — ใช้ข้ามช่องด้วยบั๊กต่อบั๊ก
- ช่องกว้างด่าน 4-5: ถอยหลังนิดเพื่อวิ่งเปิดเท้า (อย่ากดกระโดดอยู่紹ในจังหวะวิ่ง)
- แพลตฟอร์มเลื่อนขึ้น: ยืรอจังหวะ "มันจะถึงจุดสูงสุด" แล้วกระโดดต่อไปยังด่านถัดไป
