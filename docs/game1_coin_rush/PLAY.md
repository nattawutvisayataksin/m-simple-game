# คู่มือการเล่น — Kubi Coin Dash

## เนื้อเรื่อง (Goal)
ฝูงไวรัส **"Glitch Bugs"** บุกขโมย **เหรียญกองทุนเมือง KUB** ไปกองไว้ แล้วหนีกระจายไป 3 ที่ลับ:
ท่อระบายน้ำใต้เมือง, แพลตฟอร์มลอยเหนือท้องฟ้า และ **ปราสาทบิตคู** ป้อมสุดท้ายของมัน

**Kubi** — หุ่นเหรียญหัวใจอบอุ่น — ออกเดินทาง 8 ด่านเพื่อ **เก็บเหรียญคืนให้ครบกอง
แล้วไต่ขึ้นยอดปราสาท ส่งเหรียญกลับสู่โรงหล่อเหรียญเมือง KUB**

- เก็บเหรียญให้มากที่สุด · ห้ามโดนไวรัส/หนาม/หมดเวลา/ตกหุบเหว
- ชนะ = ผ่านครบ 8 ด่าน และแตะธงสุดท้ายบนยอดปราสาท

## ปุ่มควบคุม
| ปุ่ม | ทำอะไร |
|---|---|
| A / D หรือ ← / → | เดินซ้าย-ขวา |
| Space / W / ↑ | กระโดด (กดค้าง = สูง, ปล่อยกลางคัน = กระโดดสั้น) |
| Shift | วิ่งเร็ว (จำเป็นกับช่องกว้างในด่านท้าย) |
| R | เริ่มด่านใหม่ |
| Esc | กลับหน้าเมนู |
| ← / → หรือ A / D (หน้าเมนู) | **เปลี่ยนสกิน Kubi** (บันทึกลงเซฟทันที) |

การกระโดดออกแบบเอื้อผู้เล่น: Coyote time 0.12 วิ + Jump buffer 0.15 วิ — กระโดดไม่หลุดง่าย

## สกิน Kubi (เลือกในหน้าเมนู)
| สกิน | โทน |
|---|---|
| คลาสสิก | สีเดิมของ Kubi |
| สายน้ำฟ้า | น้ำเงินฟ้าเย็นสายเท่ |
| อัคคีราช | แดงชาดสายเดือด |

## เหรียญ & คะแนน
- เหรียญเงิน = 1 คะแนน · **เหรียญทอง (เรืองแสง) = 3 คะแนน**
- สถิติคะแนนสูงสุด + เวลาเร็วสุด เซฟอัตโนมัติ (พร้อมไฟล์ backup)

## ศัตรูทั้ง 4
| ศัตรู | พฤติกรรม | จัดการ |
|---|---|---|
| **Glitch Walker** (แดง) | เดินสลับทางที่ขอบพื้น | **เหยียบหัว** แล้วเด้งขึ้นได้ |
| **Glitch Hopper** (ฟ้า) | กระโดดเข้าหาผู้เล่นเป็นระยะ | เหยียบหัวได้เช่นกัน |
| **บัตบิต** — ค้างคาวไวรัส | บินลอยขึ้นลงแบบ sine เหนือช่องทาง (ด่าน 6-8) | เหยียบหัวตอนมันลอยต่ำ |
| **ชาร์เจอร์** — แมลงแดงรุกไล่ | เดินปกติ แต่เมื่อเห็นผู้เล่นระดับเดียวกัน → วิ่งรุกสุดตัว; ชนกำแพงแล้วมึนงงสักครู่ | หลบให้มันชนกำแพงเอง รอมึน แล้วเหยียบข้าม |
| หนามแดง | ปูดอยู่บนทางเดิน | กระโดดข้าม / ใช้แพลตฟอร์มข้างบน |

## ด่านทั้ง 8
1. **ถนนสายเอิ้น** (120 วิ) — ด่านไตเตอร์: พื้นต่อเนื่อง เรียนเดิน/กระโดด/เหยียบศัตรู
2. **ทุ่งเหรียญเขียว** (120 วิ) — แพลตฟอร์มเลื่อนนอน + Hopper ตัวแรก
3. **ป่าไวรัสหนา** (150 วิ) — ศัตรูกลุ่มหนา หนามแน่น
4. **หุบเหวแตกร้าว** (140 วิ) — **พื้นแตก 3 ท่อน ตกเหว = แพ้!** ใช้แพลตฟอร์มลอย + วิ่งช่วยกระโดด
5. **ยอดเขาโรงหล่อเหรียญ** (160 วิ) — ไต่บันไดเขาใหญ่ จบภารกิจเหรียญที่ธงบนยอด
6. **ท่อระบายบิต** (140 วิ) — ธีมใหม่: ท่อโลหะ + หยดน้ำเขียว · บัตบิตลอย 3 ตัว + ชาร์เจอร์ 2 ตัว
7. **ท้องฟ้าเมฆเด้ง** (150 วิ) — ฟ้าสดใส: แพลตฟอร์มเลื่อนหนัก + บัตบิต 4 ตัว + Hopper 3
8. **ปราสาทบิตคู** (160 วิ) — บอสไฟนาล: ผสมศัตรูทุกชนิด + แพลตฟอร์มลอยแนวตั้งเร็ว + ธีมปราสาทกลางคืน

ทุกด่านเริ่มด้วย **แบนเนอร์ชื่อด่าน + คำใบ้** เด้งขึ้นกลางจออัตโนมัติ

## บรรยากาศต่อธีม
- ด่าน 1-5 — ท้องฟ้าเย็นสดใส ภูเขารายล้อม
- ด่าน 6 (ท่อระบาย) — โทนมืดเขียวนิล + **หยดน้ำเขียวหล่นตลอด** + ม่านสีเย็นเต็มจอ
- ด่าน 7 (ท้องฟ้า) — ฟ้าสดใส + **ประกายทองลอยขึ้น**
- ด่าน 8 (ปราสาท) — โทนม่วงกลางคืน + **ประกายไฟลอยขึ้น** + ม่านสีม่วงเต็มจอ

## วิธีแพ้
โดนศัตรูด้านข้าง · โดนหนาม · หมดเวลา · ตกหุบเหว (ด่าน 4-5, 8) → จอแสดงเหตุ + กด R เริ่มใหม่

## เทคที่ชุดนี้ (Tips)
- เหยียบหัวศัตรูจะได้ **เด้งสูงพิเศษ** — ใช้ศัตรูเป็นบันไดได้
- ชาร์เจอร์: อย่ายืนระดับเดียวกับมันนาน — ให้มันชนกำแพงเองแล้วข้ามตอนมึน
- บัตบิต: จับจังหวะจุดต่ำสุดของการลอยแล้วกระโดดเหยียบ
- ช่องกว้างด่านท้าย: ถอยหลังหนึ่งเหยียบเพื่อวิ่งเปิดเท้าก่อนกระโดด
