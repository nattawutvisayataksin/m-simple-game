# คู่มือการเล่น — Kubi Coin Dash

## เนื้อเรื่อง (Goal)
ฝูงไวรัส **"Glitch Bugs"** บุกขโมย **เหรียญกองทุนเมือง KUB** ไปกองไว้ แล้วหนีกระจายไป 3 ที่ลับ:
ท่อระบายน้ำใต้เมือง, แพลตฟอร์มลอยเหนือท้องฟ้า และ **ปราสาทบิตคู** ป้อมสุดท้ายของมัน

**Kubi** — หุ่นเหรียญหัวใจอบอุ่น — ออกเดินทาง 8 ด่านเพื่อ **เก็บเหรียญคืนให้ครบกอง
แล้วไต่ขึ้นยอดปราสาท ส่งเหรียญกลับสู่โรงหล่อเหรียญเมือง KUB**

- เก็บเหรียญให้มากที่สุด · ห้ามโดนไวรัส/หมดเวลา/ตกหุบเหว
- ชนะ = ผ่านครบ 8 ด่าน และแตะเสาธงชัยทองบนยอดปราสาท

## ปุ่มควบคุม
| ปุ่ม | ทำอะไร |
|---|---|
| A / D หรือ ← / → | เดินซ้าย-ขวา |
| Space / W / ↑ | กระโดด — **กดซ้ำกลางอากาศได้อีก 2 ชั้น (ดับเบิลจัมพ์)** (กดค้าง = สูง, ปล่อยกลางคัน = สั้น) |
| Shift | วิ่งเร็ว (จำเป็นกับช่องกว้างในด่านท้าย) |
| R | ระหว่างเล่น: เริ่มด่านนี้ใหม่พร้อมโอกาส 3 ครั้ง · หลังตาย 1-2 ครั้ง: เล่นด่านเดิมซ้ำโดยใช้โอกาสที่เหลือ · หลังโอกาสหมด: เริ่มด่านนี้ใหม่พร้อม 3 ครั้ง |
| Space / Enter (หลังตาย) | เล่นด่านเดิมซ้ำ โดยไม่คืนโอกาสที่ใช้ไป |
| Esc | กลับหน้าเมนู |
| ← / → หรือ A / D (หน้าเมนู) | **เปลี่ยนสกิน Kubi (5 สี)** (บันทึกลงเซฟทันที) |

แต่ละด่านมี **3 โอกาส** แสดงเป็นหัวใจบน HUD เมื่อตายครั้งที่ 1 หรือ 2 สามารถกด Space/R
เพื่อเริ่มด่านเดิมใหม่ โดยเก็บจำนวนโอกาสที่เหลือไว้; เมื่อตายครั้งที่ 3 จึงเริ่มใหม่พร้อม 3 โอกาส
จอแพ้มีปุ่ม Esc กลับหน้าเมนูได้เสมอ

การกระโดดออกแบบเอื้อผู้เล่น: Coyote time 0.12 วิ + Jump buffer 0.15 วิ — กระโดดไม่หลุดง่าย
และกดกระโดดซ้ำกลางอากาศได้อีก 2 ชั้น — ตกจากสูงก็ไต่กลับขึ้นได้ ไม่ติดหลุมลูบคลำอีก

## หน้าเมนู (ตรงกับในเกม)
- เมนู 4 ตัว: **เริ่มเล่น** · **วิธีเล่น · ตัวละคร & มอนสเตอร์** · **Story · เนื้อเรื่องของเกม** · **Test · เลือกด่าน**
- ↑↓ (หรือ W/S) เลือก · Space/Enter ยืนยัน · ←/→ (หรือ A/D) เปลี่ยนสกิน (เซฟทันที)
- แผง วิธีเล่น มีปุ่มควบคุม + ข้อมูล Kubi + bestiary มอนสเตอร์ 5 ตระกูลพร้อมภาพ · แผง Story เล่าเรื่องเมือง KUB
- เมนู Test ใช้ ↑↓/←→ หรือตัวเลข 1-8 เลือกด่าน แล้วกด Space/Enter เพื่อเริ่มด่านนั้นโดยตรง
- เปิดแผงแล้วกด Esc หรือ Space เพื่อกลับเมนู

## สกิน Kubi (เลือกในหน้าเมนู)

## เหรียญ & คะแนน
- เหรียญเงิน = 1 คะแนน · **เหรียญทอง (เรืองแสง) = 3 คะแนน**
- สถิติคะแนนสูงสุด + เวลาเร็วสุด เซฟอัตโนมัติ (พร้อมไฟล์ backup)

## ศัตรูทั้ง 5 (+ มินิบอส)
| ศัตรู | พฤติกรรม | จัดการ |
|---|---|---|
| **Glitch Walker** (แดง) | เดินสลับทางที่ขอบพื้น | **เหยียบหัว** แล้วเด้งขึ้นได้ |
| **Glitch Hopper** (ฟ้า) | กระโดดเข้าหาผู้เล่นเป็นระยะ | เหยียบหัวได้เช่นกัน |
| **บัตบิต** — ค้างคาวไวรัส | บินลอยขึ้นลงแบบ sine เหนือช่องทาง (ด่าน 6-8) | เหยียบหัวตอนมันลอยต่ำ |
| **ชาร์เจอร์** — แมลงแดงรุกไล่ | เดินปกติ แต่เมื่อเห็นผู้เล่นระดับเดียวกัน → วิ่งรุกสุดตัว; ชนกำแพงแล้วมึนงงสักครู่ | หลบให้มันชนกำแพงเอง รอมึน แล้วเหยียบข้าม |
| **บิตคูผู้คุม** — มินิบอส (ด่าน 8) | ลอยจูงซ้าย-ขวาเหนือยอดปราสาท แล้วดำดิ่งพุ่งใส่ผู้เล่นทุก 4 วิ | **เหยียบ 3 ครั้ง** — โดนเหยียบแล้วจะมึน (แถบ ♥) รีบขึ้นหลบเถิก; ชนะแล้วเหรียญรางวัลกระจาย |

## ด่านทั้ง 8
1. **ถนนสายเอิ้น** (120 วิ) — ด่านไตเตอร์: พื้นต่อเนื่อง เรียนเดิน/กระโดด/เหยียบศัตรู
2. **ทุ่งเหรียญเขียว** (120 วิ) — แพลตฟอร์มเลื่อนนอน + Hopper ตัวแรก
3. **ป่าไวรัสหนา** (150 วิ) — ศัตรูกลุ่มหนา
4. **หุบเหวแตกร้าว** (140 วิ) — **พื้นแตก 3 ท่อน ตกเหว = แพ้!** ใช้แพลตฟอร์มลอย + วิ่งช่วยกระโดด
5. **ยอดเขาโรงหล่อเหรียญ** (160 วิ) — ไต่บันไดเขาใหญ่ จบภารกิจเหรียญที่ธงบนยอด
6. **ท่อระบายบิต** (140 วิ) — ธีมใหม่: ท่อโลหะ + หยดน้ำเขียว · บัตบิตลอย 3 ตัว + ชาร์เจอร์ 2 ตัว
7. **ท้องฟ้าเมฆเด้ง** (150 วิ) — ฟ้าสดใส: แพลตฟอร์มเลื่อนหนัก + บัตบิต 4 ตัว + Hopper 3
8. **ปราสาทบิตคู** (160 วิ) — บอสไฟนาล: **มินิบอส "บิตคูผู้คุม"** เหยียบ 3 ครั้งจบกอง + ผสมศัตรูทุกชนิด + แพลตฟอร์มลอยแนวตั้งเร็ว + ธีมปราสาทกลางคืน

ทุกด่านเริ่มด้วย **แบนเนอร์ชื่อด่าน + คำใบ้** เด้งขึ้นกลางจออัตโนมัติ

## บรรยากาศต่อธีม
- ด่าน 1-5 — ท้องฟ้าเย็นสดใส ภูเขารายล้อม
- ด่าน 6 (ท่อระบาย) — โทนมืดเขียวนิล + **หยดน้ำเขียวหล่นตลอด** + ม่านสีเย็นเต็มจอ
- ด่าน 7 (ท้องฟ้า) — ฟ้าสดใส + **ประกายทองลอยขึ้น**
- ด่าน 8 (ปราสาท) — โทนม่วงกลางคืน + **ประกายไฟลอยขึ้น** + ม่านสีม่วงเต็มจอ
- **เพลงรายธีม**: ด่าน 1-5 เพลงหลัก · ด่าน 6 เพลงบูบเชื่อง (90 BPM) · ด่าน 7 เพลงสดใสเร็ว (126 BPM) · ด่าน 8 เพลงครึ่งลังกล (105 BPM) — สลับอัตโนมัติเมื่อเปลี่ยนด่าน

## วิธีแพ้
โดนศัตรูด้านข้าง · หมดเวลา · ตกหุบเหว (ด่าน 4-5, 8) จะใช้โอกาส 1 ครั้ง; กด Space/R
เพื่อเล่นด่านเดิมซ้ำได้จนกว่าโอกาสทั้ง 3 จะหมด แล้วกด R เพื่อเริ่มด่านนั้นใหม่

## เทคที่ชุดนี้ (Tips)
- เหยียบหัวศัตรูจะได้ **เด้งสูงพิเศษ** — ใช้ศัตรูเป็นบันไดได้
- ช่องกว้าง/หลุมลึกเกินกระโดดเดียว: กระโดดจากพื้นแล้ว**กดซ้ำกลางอากาศอีก 2 ระลอก** (ดับเบิลจัมพ์) — ตกเหวไปลึก ๆ ก็ไต่กลับขึ้นได้
- ชาร์เจอร์: อย่ายืนระดับเดียวกับมันนาน — ให้มันชนกำแพงเองแล้วข้ามตอนมึน
- บัตบิต: จับจังหวะจุดต่ำสุดของการลอยแล้วกระโดดเหยียบ
- ช่องกว้างด่านท้าย: ถอยหลังหนึ่งเหยียบเพื่อวิ่งเปิดเท้าก่อนกระโดด
