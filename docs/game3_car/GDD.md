## ตัวตนของเกม (ดีไซน์ที่ตัดสินใจแล้ว)

- **โลก Kubi ย้ายมา 3D**: ธีมเหรียญทอง-ราชวงศ์ทองจากเกม 1/2 ยังอยู่ — เหรียญทองวางตามเลน, HUD ภาษาไทย, kart ตัวละคร Kubi จอดต้อนรับแถวเส้นชัย
- **เกมเล่นจริง (loop ครบ)**: เลือกรถ 5 แบบ → แข่งกับ AI 3 คัน → ขับด้วย WASD/ลูกศร หรือ gamepad → เก็บเหรียญและไอเท็ม → ใช้ไอเท็มด้วย Q → ผ่านประตู 3 จุดตามลำดับ (0→1→2→กลับ 0 = 1 รอบ) → ครบ 3 รอบจึงจบเกม
- **กันพลาด**: ตกสนาม (y < -8) respawn กลับเส้นชัยทันที คงผลความคืบหน้า
- **Asset และ license**: โมเดล Kenney ที่ใช้ระบุ CC0; โค้ด Starter Kit ใช้ MIT และเสียงมีที่มา/เงื่อนไขแยกตามรายการใน [ASSETS.md](./ASSETS.md)

## โครงโปรเจกต์และวิธีเปิด

มี Godot project สองชั้น อย่าสับสนระหว่างโปรเจกต์ placeholder เก่ากับเกมที่เล่นได้:

| จุดเข้า | หน้าที่ |
|---|---|
| `games/game3_car/starter-kit-racing/project.godot` | **โปรเจกต์เกมจริง**: ฉาก 3D, ระบบแข่ง, เมือง, รถ และ regression tests |
| `games/game3_car/play.bat` | Launcher สำหรับ Windows ที่ส่ง `--path` ไปยังโปรเจกต์เกมจริงด้านบน; ไฟล์นี้คาดว่า Godot 4.7.2 อยู่ใน WinGet path ของ Windows user ปัจจุบัน |
| `games/game3_car/project.godot` | **โปรเจกต์ placeholder เดิม**: เปิดแล้วได้ฉาก 2D สีเทา ไม่ใช่ Kubi Grand Prix; คงไว้เป็นโครงตั้งต้น |

วิธีเปิดจากราก repo:

```powershell
godot --path games/game3_car/starter-kit-racing
```

โปรเจกต์เกมจริงตั้ง viewport 1280×720, Forward+ และ Jolt Physics; `project.godot`
ระบุ compatibility feature `4.6` และชุดที่ตรวจล่าสุดคือ Godot 4.7.2

## สถานะงาน T1.1 (เสร็จแล้ว)

- ใช้ `scripts/town.gd` สร้างถนนวงรอบและฉากเมืองจาก asset CC0 ของ Kenney ที่เลือกใช้ ไม่ได้นำระบบควบคุม/วางอาคารจาก City Builder kit มาทับระบบรถ
- โมเดลถนนต้นฉบับ 1×1 เมตรถูกขยายเป็นช่อง 7×7 เมตร เพิ่มผิวแอสฟัลต์/เส้นประ และจัด collider ให้ระดับเดียวกับผิวถนน
- ย้ายอาคารทั้งหมดไปไว้รอบนอกสนาม; กลางวงเป็นสวนสาธารณะและลานน้ำพุแทนตึก
- ใช้พื้นเมืองโทนหินธรรมชาติ ทางเท้าวางขนานขอบถนนและไม่ยื่นเข้าเลน พร้อมเอาเสาไฟ/สิ่งกีดขวางออกจากถนน
- หลังตรวจภาพจริง พบว่าตึกสูง 11–15 ม. และพร็อพจุดตรวจใกล้เลนเกินไป; ปรับตึกเหลือ 4.7–6 ม., ลด/ย้ายป้ายจุดตรวจ และเพิ่มถนนย่านเมืองเป็นกรอบรอบสนาม
- `screenshots/overview.png` เป็นภาพหน้าเลือกรถ ใช้อ้างอิง UI ไม่ใช่หลักฐานภาพระหว่างแข่ง
- รายการ asset และที่มา: [ทะเบียน asset](./ASSETS.md)

## สถานะงาน T1.2 (ระบบทำแล้ว; ตรวจภาพจริงต่อ)

- เพิ่มเมนูเลือกรถ 5 แบบ พร้อมโปรไฟล์ความเร็วและการควบคุม; รถและ AI หยุดนิ่งจนกดเริ่มแข่ง
- เพิ่มคู่แข่ง AI 3 คันที่ขับตาม waypoint บนสนาม, เก็บไอเท็ม และใช้บูสต์/วางคราบน้ำมัน
- เพิ่มกล่องไอเท็ม 4 จุด; ผู้เล่นกด Q เพื่อใช้ไอเท็มที่เก็บได้
- แยก waypoint ขับรถออกจากการเว้นระยะเหรียญ และจัดจุดไอเท็มไม่ให้ทับจุดเริ่มหรือกันเอง
- ปรับทิศหัวรถ/ทิศขับของ AI ให้ตรงกับเส้นทาง และขยับพร็อพจุดตรวจออกจากขอบถนน

## สถานะงาน T1.3 (ทำแล้ว)

- เอาเป้าโบนัสและลังที่เคยวางชิด/ทับทางรถออกจากสนาม เพื่อไม่ให้รถชนพร็อพกลางเลน
- จัดตำแหน่งรถ AI เป็นแถวเหลื่อมกัน ไม่ให้รถซ้อนและชนกันตั้งแต่เริ่มแข่ง
- เพิ่มลานรอบอาคาร 16 จุด, เพิ่มอาคารเตี้ยเป็นแนวรอบเมือง และใส่เส้นแบ่งเลน/เส้นขอบบนถนนเมือง
- ปรับสีพื้นนอกสนามเป็นคอนกรีตโทนอุ่นขึ้น โดยคงสวนเขียวและมุมกล้องติดตามแบบเดิม
- เพิ่ม regression tests ตรวจระยะรถตอนเริ่ม, พร็อพชนได้ไม่ล้ำพื้นที่แข่ง และการเคลื่อน/ความคืบหน้าของ AI ทั้งสามคันในช่วงจำลองการแข่งขัน

## สถานะงาน T1.4 (ผ่าน regression physics tests; GUI playtest ยังต้องทำ)

- เพิ่มกำแพงเตี้ยสีแดง/ขาวที่ขอบสนามทั้งด้านในและด้านนอกเพื่อกันขับตัดสนาม
- เพิ่มซุ้ม FINISH และป้าย CHECKPOINT 1/2 ที่ประตูจริง พร้อม HUD บอกประตูถัดไป
- ใช้ trigger ประตูเป็นแถบขวางเลน ขนาด 7 × 3.6 × 2.8 ม. เพื่อให้ตรวจรถได้สม่ำเสมอ
- เปิด collision mask ระหว่างรถเพื่อให้รถชนกันและชนกำแพง/พื้นได้จริง; จัดตำแหน่งออกตัวไม่ให้ซ้อน
- เพิ่มฟิสิกส์ regression tests ที่จำลองรถชนรถ รถชนกำแพง และการผ่าน Gate 0→1→2→0 ด้วย Jolt Physics

## สถานะงาน T1.5 (แก้ตามผลตรวจภาพและ physics)

- เปลี่ยนกำแพงขอบสนามจากกรอบสี่เหลี่ยมเป็นชิ้นตรงต่อกับส่วนโค้งตามรัศมีของถนน
  ป้องกันกำแพงสีแดง/ขาวพาดตัดเข้าเลนตรงโค้งทั้งสี่มุม
- ตรวจ physics ray ทั้งขอบใน/นอกของโค้งทั้งสี่ และจำลองรถชนกำแพงโค้งจริงที่ระดับขับปกติ
- ขยายแนวถนนย่านเมืองให้ผิวถนนชนเชื่อมกันตรงสี่แยก ไม่เหลือช่องว่างที่ปลายถนน

## เทส (headless)

รันจากราก repo:

```powershell
godot --headless --path games/game3_car/starter-kit-racing `
  --scene res://tests/test_game3_runner.tscn
```

ผลตรวจรอบนี้: **53 PASS / 0 FAIL**, exit code 0. ครอบคลุมฉาก/เมือง, ถนนเมืองต่อถึงกัน,
ขอบกำแพงโค้งทั้งสี่ไม่กินเข้าเลน, ระยะออกตัว, AI, การเก็บเหรียญ/ไอเท็ม, การควบคุม,

หมายเหตุ: test runner ใช้ Jolt และ collider จริงแบบ headless; ยังไม่ใช่การทดสอบด้วยคน
ในหน้าต่างเกม จึงยังต้องตรวจความรู้สึกการชน การมองเห็น และการขับครบสนามด้วยมือ
Godot แจ้ง ObjectDB 20 รายการและ resource 4 รายการยังถูกใช้อยู่ตอน teardown แม้เทสผ่าน;
ควรติดตาม cleanup ของ test runner ในรอบถัดไป

## Starter Kit และ asset ที่มี

ที่อยู่: `games/game3_car/starter-kit-racing/` — โฟลเดอร์นี้เป็นทั้งโปรเจกต์เกมจริงและที่เก็บ Starter Kit ที่นำมาต่อยอด

| ของ | ที่เก็บ |
|---|---|
| ระบบรถ arcade ที่นำมาต่อยอด | `scripts/vehicle.gd`, `vehicle-motorcycle.gd`, `scenes/vehicle*.tscn` |
| ฉากหลักปัจจุบันเป็นเมือง/สนามที่สร้างจากสคริปต์; GridMap เดิมเหลือเป็น fallback | `scenes/main.tscn`, `scripts/town.gd`, `scripts/game.gd`, `models/*.glb` |
| รถที่เลือกได้ 5 แบบ: race-future และ truck 4 สี | `scripts/game.gd` (`CAR_OPTIONS`), `models/race-future.glb`, `models/vehicle-truck-*.glb` |
| มอเตอร์ไซค์จากชุดต้นฉบับ | `vehicle-motorcycle.gd`, `scenes/vehicle-motorcycle.tscn`; มีไฟล์อยู่แต่ไม่ใช่ตัวเลือกเมนูปัจจุบัน |
| เอฟเฟกต์ควันบุหรี่ท้าย + impact | `sprites/smoke.png`, `audio/*.ogg` |
| เรนเดอร์ Forward+ + **Jolt Physics** + MSAA | ตั้งไว้ใน `project.godot`; compatibility feature 4.6, ตรวจรันด้วย Godot 4.7.2 |

แนวที่เลือกคือ **เกมแข่งรถ 3D** โดยต่อยอดระบบขับจาก Starter Kit Racing และใช้เฉพาะ asset เมืองที่จำเป็น ไม่คัดลอกโปรเจกต์ City Builder ทั้งชุด
