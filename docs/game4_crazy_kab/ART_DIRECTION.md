## 1. ภาพรวมสไตล์

- **แนว**: พิกเซลอาร์เคด top-down แนว Crazy Taxi ยุคตึกย่านเมืองคูบี้ — ฉาก 1152×648 คงที่, pixel filter ปิด (คมทุกพิกเซล)
- **เส้นแบ่งงานสไปรต์ vs โค้ด**: ยานพาหนะ/อุปสรรค/ผู้โดยสาร = สไปรต์ PixelLab · ถนน/ตึก/ฟุตบาท/ทางม้าลาย/หมุด/ลูกศร/HUD = วาดโค้ดล้วน (ควบคุมสีได้ 100%)
- **กฎมุมภาพ**: สไปรต์รถทั้งชุดหันลงซ้าย 135° → โค้ดชดเชย `SPRITE_ANG = PI * 0.75` ห้ามตักภาพใหม่ที่มุมอื่นโดยแจ้งตัวเลขใน doc นี้

## 5. ตัวอักษรและ HUD

- ฟอนต์: `ThemeDB.fallback_font` ทั้งเกม (ไม่เอา custom) — โทนจอเมนูพื้นเข้ม (0.10, 0.12, 0.16)
- ปุ่มเมนู: พื้นเทาน้ำเงิน (0.16, 0.20, 0.28) hover ทอง (0.95, 0.78, 0.25) + ขอบขาวโปร่ง

## 6. จูนภาพให้ผู้เล่นรู้สึก (game feel ฝีมือโค้ด)

1. **เงาทุกตัวมีชีวิต**: รถใช้เงาวงรี scale (1.05, 0.62) ขนานทิศ rotation จริง
2. **อะไรเกิดมีอาการ**: เบรก = ไฟแดง, โดนโกเลม = ดาววนหัว, สไลม์ = ตัวยวบ, หมุดรับมีกบยืนรอเสมอ
3. **ทิปลอยขึ้นฟ้า**: อยู่ 1.6 วิ ลอยขึ้นด้วยความเร็ว 24px/วิ
4. **เสียงขับภาพ** (G8 ใหม่): รับ "pickup" / เงิน "drop" / ดริฟท์ "squeal" / เฉียด "whoosh" / แรมพ์ "boing" / โกเลม "thud" / สไลม์ "squish" / เมนู "click" / จบเกมจิงเกิล win-lose — สังเคราะห์ล้วนใน `tools/generate_audio.ps1`

## 7. ข้อห้ามตอนเพิ่มภาพใหม่

- ห้ามคำ "stone ground / terrain" ใน `-Description` — ผลพวงจะมีฐานหินฉากมาเกาะยานพาหนะ (เคยเผ็ดที่ car_golem v1)
- `-View` ยอมได้เท่านั้น: `side` · `low top-down` · `high top-down` (front พัง 422)
- ทุกภาพใหม่ต้องประกาศมุมภาพลงเกม/เอกสารเสมอ — มุมสไปรต์คือหัวใจการหมุนวาด ถ้าเอียงผิดจากคอนแวนต์ 135° ต้องแก้ SPRITE_ANG ใน car.gd/play.gd ทั้งคู่
