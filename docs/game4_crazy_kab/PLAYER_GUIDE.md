## 1. เป้าหมายของเกม

นาฬิกาเกม **120 วิ** (ถอยหลังตลอด หมด = จบเกม) — รับลูกค้าที่หมุดแล้วส่งถึงปลายทางให้ได้ **เงินรวมมากที่สุด**

- ส่งเร็ว = ทิปถล่มทลาย (ค่าโดยสารคูณเท่าตัว)
- ลีลาเสี่ยง (เฉียด/ดริฟท์/แรมพ์) ทำเงินเพิ่ม
- จบรอบบันทึกสถิติอัตโนมัติ `user://taxi_best.json` (atomic, พังไฟล์ก็เริ่มใหม่ไม่ค้าง)

## 2. เมนูหลัก 5 ปุ่ม

| ปุ่ม | เนื้อหา |
|---|---|
| **เริ่มเล่น** | ลงสนามเลย ลูกค้าคนแรกโผล่ภายในไม่กี่วินาที |
| **เรื่องของเกม** | เนื้อเรื่อง คืนทุนจากเกม 2 (โลก Kubi) |
| **วิธีเล่น** | สรุปการควบคุม + การรับ-ส่ง + ทิปลีลา |
| **คู่มือค่าต่างๆ ของเกม** | ตารางเวลา / ความเร็วรถ / สูตรเงิน / เงื่อนไขปลดล็อก |
| **รถและสถิติ** | สถิติเงินสูงสุด-ลูกค้าสูงสุด + รถที่ปลดล็อกแล้ว |

## 3. การควบคุม

| ปุ่ม | ทำอะไร |
|---|---|
| **ลูกศร / WASD** | ขับ (ขึ้น=เร่ง, ลง=ถอย, ซ้ายขวา=เลี้ยวเหมือนรถจริง ยิ่งเร็วยิ่งแตะ) |
| **Space** | เบรกมือ — ปลดล็อกโหมดดริฟท์ (เลี้ยวแหลมขึ้น 1.45 เท่า, รถลื่น) |
| **R** | เริ่มรอบใหม่ (จะบนจอจบก็ได้) |
| **ESC** | กลับเมนูหลัก |

## 4. ลูปรับ-ส่ง (หัวใจเกม)

1. **หมุดเหลือง = ป้ายรับ** — หยุดรถ (ช้ากว่า 70 px/วิ) ในวงรัศมี 70px → กบลูกค้าขึ้นรถ (หัวเขายืนรอบนหมุดอยู่แล้ว)
2. จอ HUD ขวาบนโชว์ **เข็มนับถอยหลังของทริปสีเขียว** + ค่าโดยสารที่จะได้
3. ลูกศรสีเหลืองติดหลังรถชี้เป้าทุกเมื่อ; หมุดเป้าสี **ฟ้า = จุดส่ง**
4. หยุดในวงจุดส่งก่อนเวลา → เงินเข้ากระเป๋า, ลูกค้าคนถัดใหม่โผล่ใน ~0.6 วิ

## 5. ตัวเลขเงิน (สูตรตรงจากโค้ด)

| รายการ | ค่า |
|---|---|
| ค่าโดยสาร (fare) | `50 + ระยะทาง/10` บาท (ระยะ 400px = 90 บาท) |
| เวลาต่อทริป | `15 + ระยะ/60` วิ (ต่ำสุด 18, สูงสุด 45) |
| ทิปส่งเร็ว | เวลาที่เหลือ ≥50% → **×2.0**, ≥25% → **×1.5**, ช้ากว่านั้น → ×1.0 |
| ทิปเฉียดรถคนอื่น | **+5** (ห่างแค่ 48px ตอนวิ่งเร็วกว่า 240, ทุก 1 วิได้ครั้งเดียว) |
| ทิปดริฟท์ | **+10** ทุก 0.8 วิที่ร้องล้อ |
| ทิปแรมพ์ (แท่งเทากลางแผนที่) | **+20** เมื่อผ่านเร็วกว่า 250 ครั้งละครั้งต่อการผ่าน |
| คอมโบ | ดอกเบี้ยสะสม (แสดง HUD) — พลาดโทริปจะตัดคอมโบแล้วเริ่มเก็บใหม่ |
| **ลูกค้า VIP** (สุ่ม ~12%) | แหวนทองกระพริบรอบหมุดรับ + มงกุฎบนหัว — ค่าโดยสาร **×3** (ตัวคูณทิปยังจ่ายปกติ); HUD แถบสีทองกระพริบ |

## 6. รถ 3 คัน (ปลดล็อกจากเงินรอบเดียว)

| รถ | เริ่มมีไหม | ความเร็วสูงสุด | เร่ง | เบรก | เลี้ยว (rad/วิ) |
|---|---|---|---|---|---|
| **Kubi Cab** | เริ่มเกมมีเลย | 380 | 520 | 620 | 2.6 |
| **กิ้งก่าซิ่ง** | ปลดล็อกที่รอบได้เงิน **500** | 440 (เร็วสุด) | 480 | 520 | 3.1 |
| **โกเลมแท็กซี่** | ปลดล็อกที่รอบได้เงิน **1,200** | 310 | 620 | 900 (เบรกสุดแรง) | 2.0 |

- เงื่อนไขนับจาก **เงินของรอบเดียว** นั้น ๆ (ไม่ใช่ยอดสะสมหลายรอบ)
- ปลดล็อกแล้ว = เข้าชื่อจอจบ (แถบเพิ่ม "ปลดล็อกรถใหม่")

### อู่อัปเกรด (หน้า "รถและอู่อัปเกรด" ในเมนู)

- **เงินสะสมทุกกะ** รวมกันซื้อเลเวลรถ **ถาวร** — ราคา Lv1 **400** / Lv2 **900** / Lv3 **1,800** บาท
- แต่ละเลเวล: สปีดสูงสุด **+8%** · เร่ง/เบรก/เลี้ยว **+6%** — สูงสุด **Lv3** (Kubi Lv2 ตัวอย่าง: สปีด 380→440)
- เลือก "ใช้คันนี้" ตั้งรถประจำกะ — กะถัดไปเริ่มเกมด้วยคัน + เลเวลที่เลือกทันที
- HUD บอกตลอด: "รับได้ X · พลาด Y · <ชื่อรถ> Lv<n>"

## 7. อุปสรรคบนถนน

| อุปสรรค | เจอเมื่อไหร่ | สิ่งเกิดต่อเมื่อชน |
|---|---|---|
| **สไลม์เขียว 5 ตัว** | กระจายทั่วเมืองเคลื่อนไหวตลอด | รถชะลอ 2 วิ (ความเร็วสูงสุดเหลือ 40%) เวลาทริปยังนับต่อ |
| **โกเลมหินข้ามถนน** | เกิดใหม่ทุก 4-7 วิ, ข้ามถนนแนวนอนช้า ๆ | ชนเต็ม ๆ → รถหมุนเสีย 1 วิ (จุดเสียเวลาทริปที่แพงที่สุด) |
| **รถจราจร 4 คัน** | วิ่งถนน 4 เลนตลอดรอบ (สีเทา/ฟ้าเข้ม/แดงอิฐ/ทอง) | เฉียดให้ดีได้ +5 ทิปแทนการชน |

> **ครึ่งเกมหลัง (วินาที 61+)**: เมืองหน่วงหนัก — รถจราจร/สไลม์/โกเลมเร็วขึ้น ~30% วางแผนเส้นทางที่เหลือคิดเป็นดามัจจะเปิดทิปชนทุ่ม

## 8. เคล็ดลับส่งเงินอร่อย

1. **แผนที่อ่านง่าย** — ถนนแนวนอน y=110/294/478, แนวตั้ง x=170/576/982; คิดเลยเส้นตัดระหว่างหมุดก่อนออกเดินทาง
2. **ดริฟท์มือแต่กำไรตอบแทน** — โค้งยาวกด Space+เลี้ยว ความเร็วหายน้อยกว่าเบรกธรรมดา + ได้ +10 ต่อทุก 0.8 วิ
3. **สไลม์ฆ่าไม่ได้** — เส้นทางผ่านบล็อกสไลม์ = ถือว่าเสีย 2 วิอยู่ในเงื่อนไขเวลาทริป
4. **โกเลมชนไม่มีวิธีชดเชย** — เสียเวลา 1 วิทุกครั้งที่ชน เพราะฉะนั้นก้มมองถนนข้างหน้าเสมอ
5. **แรมพ์กลางแผนที่ +20 ฟรี** — อยากโชว์เก่ง วางเส้นทริปให้ผ่านแรมพ์กลางทางให้ได้
6. **นาฬิกาเกมเหลือน้อยให้เลือกทริปสั้น** — ทริป 18 วิกำไรต่อนาทีคุ้มกว่าเปิดทริปไกล 45 วิเสี่ยงฉุดเวลา
