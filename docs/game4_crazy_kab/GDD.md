# GDD — แท็กซี่คู่ฟ้า (Kubi Crazy Cab) · เกม 4

> สร้าง 2026-11-01 · แรงบันดาลใจ: Crazy Taxi (1999, Hitmaker/Sega), The Simpsons: Road Rage, Micro Machines (top-down), Burnout (tips จากการเสี่ยง) — เครื่องมือ: Godot 4.7.2 + PixelLab (Key C: 31/40 คงเหลือ 31)

## 1. Goal ของเกม (ทำไมเกมนี้จึงสนุก)

**Arcade score-attack แบบ Crazy Taxi:** รับประชาชน → ส่งถึงเป้าในเวลาที่จำกัด → ยิ่งเร็ว ยิ่งได้ทิป → นาฬิกาเกมรวมหมด = จบเกม เทียบสถิติเงินสูงสุด

- **เรียนรู้ใน 5 วินาที:** ลูกศร = ขับ · หมุดเหลือง = ผู้โดยสาร · นาฬิกาถอยหลัง = เร่ง
- **รอบสั้น 2 นาที** จบแล้วเห็นสถิติทันที — ต้องเงินตอเพลิงขึ้นทุกรอบก่อนจอจบสถิติใหม่
- เสียงจังหวะเร็ว (อ้าง audio pipeline เดิมของเกม 2) เกมจบเห็นสถิติทันที → ความอยากเล่นใหม่สูง

## 2. เนื้อเรื่อง (ต่อจากเกม 2 เรียบร้อย)

หลังศึกปราสาทจบ แผ่นดินเริ่มฟื้น ประชาชนในเมืองต้องการรถโดยสาร — ฮีโร่ Kubi เลยเปิดบริการแท็กซี่ รับส่งพลเมืองให้ทันงานใหญ่ของแต่ละวัน

- **ศัตรู = อุปสรรคบนถนน ไม่ใช่มอนที่ต้องฆ่า:** สไลม์บานไปบนถนนชะลอรถ, โกเลมหินข้ามโค้ง (ชน = หมุนเสีย 1 วิ), ค้างคาวกลุ่มลอยขวางทาง
- บอส KUBIT เป็นลูกค้าถ้ำพิเศษช่วงเกมหลัง — จ่ายค่าโดยสารบานปลายได้หมายป้ายสุท้าย

## 3. Gameplay หลัก (ตัวเลขออกแบบ — ดำเนิน implement แล้วยืนยันที่โค้ดจริงให้ PLAYER_GUIDE)

### 3.1 เวลา
| ตัวแปร | ค่า | ที่มา |
|---|---|---|
| เวลาเกมรวมเริ่ม | **120 วิ** | แนว Crazy Taxi (รีบ มีแต่ feedback) |
| เวลาต่อรอบผู้โดยสาร | `15 + ระยะ/60` วิ (max 45) | ตัวชี้สีความไกลแบบ CT |
| ส่งทันเวลา | ได้ fare + ทิปตาม % เวลาที่เหลือ |
| ส่งไม่ทัน (หมดเวลา) | ผู้โดยสารหนี — ไม่ได้เงิน และเสียเวลาเกมรวมจริง ๆ |

### 3.2 รถ (ค่าจาก CAR_DEFS จากโค้ดดับสุด)
| รถ | ความเร็วสูงสุด | เร่ง | เบรก | มุมหัน | จุดเด่น |
|---|---|---|---|---|---|
| **Kubi Cab** (ปลดเริ่ม) | 380 px/วิ | 520 | 620 | 2.6 rad/วิ | สมดุลทุกสาย |
| **กิ้งก่าซิ่ง** (กำไรรวม 500) | 440 | 480 | 520 | 3.1 | เร็วสุด แต่เบรกอ่อน — เลี้ยวต้องเว้นช่อง |
| **โกเลมแท็กซี่** (กำไรรวม 1,200) | 310 | 620 | 900 | 2.0 | ชนอุปสรรคไม่หมุน — หนาที่สุด |

### 3.3 การตมรเงิน
| ช่อเงิน | สูตร |
|---|---|
| ค่าแท็กซี่ (fare) | `50 + floor(ระยะ/10)` บาท |
| ทิปส่งเร็ว | ทัน 50% เวลา → ×2 · ทัน 25% → ×1.5 · ช้ากว่านั้น ×1 |
| ทิปจากลีลา | near-miss +5 · ดริฟท์ทุก 0.8 วิ +10 · โดดแรมพ์ +20 |

### 3.4 ควบคุม
- **ลูกศร/WASD** = ขับ (เร่ง/ถอย/เลี้ยว) · **Space** = เบรกมือ (ดริฟท์) · **R** = เริ่มใหม่ · **ESC** = เมนู
- ปลายทางมีลูกศร-เสาแสงชี้ชัดตลอด (สไตล์เสาป้ายแขวนแนว CT)

### 3.5 แผนที่ (top-down pixel 1152×648, stretch canvas_items)
| แผนที่ | แนวถนน | ระดับ |
|---|---|---|

| map 2 ชายเลขาววาด (stretch) | โค้งยาวแนวชายทะเล — ระยะไกลได้เงินโต | เก็บเงิน |
